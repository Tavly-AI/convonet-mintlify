Connect a Telnyx number to Tavly with [elastic SIP trunking](/deploy/custom-telephony), so your agents can make and receive calls on numbers you own in Telnyx. Create an FQDN trunk, configure routing and codecs, set up outbound auth, then import the number into Tavly.

## What is Telnyx Elastic SIP Trunking integration?

**Telnyx Elastic SIP Trunking integration** links your Telnyx phone numbers and private voice network directly with Tavly conversational AI agents. Through fully qualified domain name (FQDN) routing, SRV record lookups, credential authentication, and TCP transport, teams execute inbound and outbound AI voice calls while preserving carrier infrastructure and negotiated rates.

Connecting Telnyx with Tavly provides enterprise-grade telephony controls with global low-latency media processing:

| Configuration Component | Recommended Setting | Protocol / Specification | Description |
| :--- | :--- | :--- | :--- |
| **Inbound FQDN (Origination)** | `sip.tavlyai.com` | DNS SRV Record | Routes inbound PSTN calls from Telnyx to Tavly voice agents |
| **Transport Protocol** | `TCP` | RFC 3261 | Ensures reliable packet delivery for SIP signaling streams |
| **Audio Codecs** | `G.722`, `G.711U`, `G.711A` | Wideband / Narrowband Audio | Provides high-fidelity audio for accurate speech recognition |
| **Number Format** | `+E.164` | ITU-T E.164 | Canonical international phone number formatting |
| **Outbound Authentication** | Credentials (Username/Password) | Digest Authentication | Secures outbound SIP termination requests |
| **Mandatory SIP Header** | `X-Telnyx-Username: <username>` | Custom SIP Header | Identifies credential owner on outbound calls |

## How do you configure a Telnyx Elastic SIP Trunk step by step?

To configure a **Telnyx Elastic SIP Trunk**, provision an FQDN trunk in the Telnyx Portal pointing to Tavly SIP gateway, establish credential authentication, set inbound transport to TCP with standard codecs, assign an outbound voice profile, associate numbers to the trunk, and import your numbers into Tavly console.

Follow these step-by-step instructions to complete the setup:

<Steps>
  <Step title="Create elastic SIP trunking">
    1. Create the trunk, select **FQDN** as the connection type, and assign a descriptive name:

    2. Add Tavly FQDN:

    Add the FQDN of Tavly's SIP server: `sip.tavlyai.com`. Select `SRV` as the DNS record type:

    <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-telephony/telnyx/setting.jpeg?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=5c21b0780b66885597c416d98dd8fe1e" data-path="images/custom-telephony/telnyx/setting.jpeg" />

    3. Set up outbound calls authentication:

    Select **Credentials** as the authentication method, and specify the username and password. You will need to use this username and password when importing the number into Tavly:

    <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-telephony/telnyx/outbound-auth.jpeg?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=87ba94312ebb879e7dc9b19ed27e5bf6" data-path="images/custom-telephony/telnyx/outbound-auth.jpeg" />

    <Note>
      Telnyx requires the header `X-Telnyx-Username: <username>` to be included in outbound calls when using credentials as the authentication mechanism. See Telnyx [documentation](https://support.telnyx.com/en/articles/5271423-guide-to-sip-anchorsite-settings#h_0b59d6992a) for more details. You can find details on adding [custom SIP headers](/build/telephony/sip-headers), or on the [Make outbound calls](/deploy/outbound-calls#how-do-you-make-outbound-calls-programmatically-via-api) page.

    4. Set up inbound settings:

    * Select `+E.164` as the number format.
    * Select `G722`, `G711U`, and `G711A` as the active audio codecs.
    * Select `TCP` as the transport method (TCP is strongly recommended over UDP for signaling reliability).
    * Select your preferred SIP region.

## How do you import Telnyx numbers into Tavly?

To **import Telnyx numbers into Tavly**, enter your phone number in E.164 format, specify Telnyx regional termination FQDN, input your trunk authentication credentials, and inject the mandatory custom SIP header. Once registered, agents initiate and receive calls directly through the Tavly dashboard or programmatic telephony REST APIs.

Follow these steps to import and manage your Telnyx phone numbers:

<Steps>
  <Step title="Import numbers via dashboard or API">
    Now that the number is configured with your elastic SIP trunk, import it into Tavly so our gateway knows how to route incoming and outgoing calls:

    <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-telephony/import-number.png?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=19c4a219923eb0adc03c807cb8d767c3" data-path="images/custom-telephony/import-number.png" />

    Supply Telnyx's FQDN as the termination SIP URI. You can find your FQDN based on your choice of SIP region in the [Telnyx SIP documentation](https://sip.telnyx.com/) (for example, `sip.telnyx.com`). Supply the username, password, and any additional SIP headers configured earlier during outbound authentication:

    <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-telephony/import-number-detail-telnyx.png?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=bdd4e9d406b74aa12a779c94c9d8697d" data-path="images/custom-telephony/import-number-detail-telnyx.png" />

    You can also import numbers programmatically using the [Import Number API](/api-references/import-phone-number).
  </Step>
  <Step title="Manage and test active numbers">
    Once the number is imported, you can make and receive calls with it identically to numbers purchased directly from Tavly:

    * **Place calls immediately**: View the number in your dashboard and initiate calls directly from the console interface.
    * **Automate via API**: Use the [Create Phone Call API](/api-references/create-phone-call) to dispatch calls programmatically.
    * **Disconnect or delete**: To disconnect the number from Tavly routing, delete it from the dashboard or execute the [Delete Number API](/api-references/delete-phone-number).
  </Step>
</Steps>

## How do you troubleshoot Telnyx SIP trunking issues?

To troubleshoot **Telnyx SIP trunking issues**, verify that inbound routing uses SRV records pointing to Tavly gateway over TCP transport, validate outbound credential accuracy, and ensure the username header is included in termination requests. Inspect SIP INVITE handshakes and download Wireshark PCAP logs to isolate signaling failures.

Examine the following diagnostics when encountering call connectivity errors:

* **Inbound Call Failures**: Verify that the FQDN in your Telnyx trunk settings points to `sip.tavlyai.com` with `SRV` selected as the DNS record type. Check that inbound transport is set to `TCP` and that the assigned number format matches `+E.164`.
* **Outbound Call Failures**: Confirm that the regional termination FQDN matches your assigned Telnyx anchor site, check the validity of your SIP username and password, and verify that the `X-Telnyx-Username` header is included in the outbound request payload.
* **SIP Signaling Diagnostics**: Refer to [Debug outbound call](/reliability/debug-outbound-call) for common SIP error codes (e.g., 401 Unauthorized, 403 Forbidden, 408 Request Timeout), or review [debug SIP calls with PCAP files](/reliability/debug-calls-pcap) to inspect the packet signaling directly in Wireshark.
