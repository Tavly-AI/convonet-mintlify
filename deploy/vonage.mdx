Connect a Vonage number to Tavly with [SIP trunking](/deploy/custom-telephony), so your agents can make and receive calls on numbers you own in Vonage. Set up termination (outbound) and origination (inbound), add credentials, then import the number into Tavly.

## What is Vonage SIP Trunking integration?

**Vonage SIP Trunking integration** connects phone numbers provisioned in your Vonage dashboard to Tavly conversational voice agents via Session Initiation Protocol (SIP). By configuring bidirectional origination and termination routing with credential authentication, teams preserve their existing Vonage carrier infrastructure while automating interactive inbound customer calls and outbound contact center campaigns.

Connecting Vonage with Tavly provides carrier-grade voice infrastructure with flexible call routing:

| SIP Route Direction | Traffic Direction | Configuration Endpoint | Authentication Mechanism |
| :--- | :--- | :--- | :--- |
| **Origination (Inbound)** | Vonage PSTN → Tavly Agent | `sip.tavlyai.com` | Open gateway routing |
| **Termination (Outbound)** | Tavly Agent → Vonage PSTN | Vonage Termination SIP URI | Digest Authentication (Username & Password) |

## How do you configure a Vonage Elastic SIP Trunk step by step?

To configure a **Vonage Elastic SIP Trunk**, navigate to the Vonage SIP dashboard, select custom provider settings, define outbound termination credentials, and set Tavly SIP gateway as the origination URI. Then, assign numbers to the trunk and import credentials into Tavly to activate bidirectional voice routing.

## How do you import Vonage phone numbers into Tavly?

To **import Vonage phone numbers into Tavly**, enter your phone number in E.164 format, supply your Vonage termination SIP URI, and provide the authentication username and password created during trunk configuration. Once imported, agents immediately place and receive calls through Tavly console or programmatic telephony REST APIs.

Follow these steps to import and manage your numbers:

<Steps>
  <Step title="Import numbers via dashboard or API">
    Now that the number is configured with your elastic SIP trunk, import it into Tavly so our platform knows how to route incoming and outgoing traffic:

    Supply the termination SIP URI, username, and password configured during Step 1:

    <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-telephony/vonage/import.jpeg?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=f1938fc65d930aa91376966506137078" data-path="images/custom-telephony/vonage/import.jpeg" />

    You can also import numbers programmatically via the [Import Number API](/api-references/import-phone-number).
  </Step>

  <Step title="Bind agents and place calls">
    Now that the number is imported, you can make and receive calls with it identically to a number purchased directly from Tavly:

    * **Dashboard management**: The number displays in your dashboard, where you can bind AI voice agents and initiate test calls directly from the user interface.
    * **Inbound calls**: Review the [Receive inbound calls](/deploy/receive-calls) guide to assign an AI conversational agent to your number.
    * **Outbound campaigns**: Check out the [Make outbound calls](/deploy/outbound-calls) guide to learn how to dispatch automated calls via API or dashboard.
    * **Number disconnection**: To release the number from Tavly routing, delete it from the dashboard or execute the [Delete Number API](/api-references/delete-phone-number).
  </Step>
</Steps>

## How do you troubleshoot Vonage SIP trunking issues?

To troubleshoot **Vonage SIP trunking issues**, verify that your origination URI points to Tavly gateway, validate outbound termination credentials against Vonage console settings, and confirm that assigned phone numbers are linked to the trunk. Inspect SIP response codes and packet captures to isolate carrier authentication or routing failures.

Check the following diagnostic steps if call connectivity encounters errors:

* **Inbound Call Failures**: If an inbound call fails, verify that the origination SIP URI on your Vonage trunk matches `sip.tavlyai.com` exactly and that the inbound number is correctly assigned to the trunk.
* **Outbound Call Failures**: If an outbound call fails, verify the termination SIP URI, authentication username, and password that you supplied to Tavly. Confirm that your Vonage account balance and dialing permissions support the destination number.
* **SIP Error Diagnostics**: Consult [Debug outbound call](/reliability/debug-outbound-call) for common SIP error status codes, or review [debug SIP calls with PCAP files](/reliability/debug-calls-pcap) to inspect the signaling handshakes in Wireshark.
