## What is TTS Fallback?

TTS Fallback is a critical redundancy mechanism for live telephony. If your primary third-party speech synthesis engine experiences service disruptions or latency spikes, this system immediately routes traffic to a backup voice so the caller never experiences dropped audio.

<Note> **Automated Routing:** If your agent uses a [Platform Voice](/build/platform-voices) or a native Tavly library model, failover is managed completely automatically by internal routing infrastructure. You only need to manually configure fallback policies when deploying custom voice clones or external third-party engines.</Note>

## How does Default Failover operate?

When an agent running a third-party voice lacks a user-defined fallback sequence, Tavly automatically executes a standardized recovery plan to keep the call alive.

* **Gender Continuity:** Tavly attempts to select an alternate voice that matches the original voice model's gender metadata.
* **Cascading Priority:** The system iterates sequentially through an internal roster of backup voices, advancing down the list if subsequent providers also report errors.
* **Session Stickiness:** After switching to a fallback voice mid-call, the agent remains on that backup model for the duration of the conversation. It does not revert to the primary voice mid-session, avoiding jarring vocal shifts for the caller.

## How do you configure a Custom Fallback Plan?

Defining a custom fallback plan allows you to explicitly pre-select replacement voices that share comparable tone, pacing, and timbre to your primary voice, making synthesis transitions virtually imperceptible to the caller.

When building your fallback roster, you must adhere to the following configuration constraints:

* **Provider Isolation:** Every entry in your fallback list must utilize an independent text-to-speech provider.
* **Primary Exclusion:** Fallback voices cannot share the exact same underlying provider as your primary voice.
* **Multi-Tier Redundancy:** You can chain multiple secondary voices together to establish robust multi-tier failover protection.
