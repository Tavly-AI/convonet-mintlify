## How does Language Support work?

Any language your agent uses must be covered by **both** a voice (text-to-speech) provider and a speech recognition (ASR) provider simultaneously. 

This page provides a hard reference for which providers support which languages. The codes shown in the tables are exactly what the API's `language` field explicitly accepts. Where a language has several locale variants (e.g., US versus British English), they share the exact same provider support.

<Note> **The Source of Truth:** Provider coverage shifts dynamically. The dashboard's language picker is always the live source of truth—it automatically greys out unsupported combinations. Treat the tables below as a planning reference, and confirm exact combinations in the dashboard.</Note>

## Which providers support Text-to-Speech (Voice)?

A checkmark (✓) means at least **one** of the provider's voice models supports the language natively. However, some providers restrict specific languages strictly to certain models (detailed below). 

For a broader evaluation of quality and features across these providers, review the [TTS provider comparison](/build/tts-provider-comparison).

## What are the Model-Level Restrictions?

While most providers support their full language roster regardless of the model chosen, several providers restrict language availability exclusively to specific models.

**ElevenLabs**

| Model                    | Languages                                                                                                                                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `eleven_v3`              | All languages in the ElevenLabs column above                                                                                                                                                                                                                                                     |
| `eleven_flash_v2_5`      | English, Japanese, Chinese, German, Hindi, French, Korean, Portuguese, Italian, Spanish, Indonesian, Dutch, Turkish, Filipino, Polish, Swedish, Bulgarian, Romanian, Arabic, Czech, Greek, Finnish, Croatian, Malay, Slovak, Danish, Tamil, Ukrainian, Russian, Hungarian, Norwegian, Vietnamese |
| `eleven_multilingual_v2` | Same as `eleven_flash_v2_5` above, **minus** Hungarian, Norwegian, and Vietnamese                                                                                                                                                                                                                |
| `eleven_flash_v2`        | English only                                                                                                                                                                                                                                                                                     |

**Fish Audio**

| Model                | Languages                                                                                                        |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `s2-pro`, `s2.1-pro` | All languages in the Fish Audio column above                                                                     |
| `s1`                 | English, Chinese, Japanese, German, French, Spanish, Korean, Arabic, Russian, Dutch, Italian, Polish, Portuguese |

**Unrestricted Providers:**
**OpenAI** (`tts-1`, `gpt-4o-mini-tts`), **Cartesia** (`sonic-3`, `sonic-3-latest`, `sonic-3.5`), **MiniMax** (`speech-02-turbo`, `speech-2.8-turbo`), and **Inworld** (`inworld-tts-2`, `inworld-tts-2-flash`) support their entire language lists on every single model they offer.

## Which providers support Speech Recognition (ASR)?

A checkmark (✓) means the ASR provider can accurately transcribe that language. By default, Tavly automatically routes across ASR providers dynamically to optimize for latency or accuracy.

You can explicitly pin a specific provider via a custom speech-to-text config, provided it covers your agent's required languages. See [Speech recognition providers](/build/asr-providers).

## Multilingual Agents

For a [Multilingual Agent](/agent/multilingual), every single language you select must be explicitly covered by *both* one voice provider and one ASR provider capable of handling the entire set together. 

If no single provider covers the entire combination, the dashboard aggressively blocks the selection to prevent runtime errors.
