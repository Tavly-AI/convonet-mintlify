## What is a Chat Agent?

**Chat agents** manage dynamic, text-based conversations with your users. Because they rely on the exact same prompts, [functions](/build/add-function-calling), and [knowledge bases](/build/knowledge-base) as voice agents, you can seamlessly extend your existing phone logic into text channels like websites, SMS, or mobile apps.

<Note> **Third-Party Integrations:** Tavly does not provide native integrations for platforms like WhatsApp or Messenger. Outside of the [Website Widget](/deploy/chat-widget) and [SMS](/deploy/enable-sms), you must connect other channels manually using the [Chat API](/api-references/create-chat).</Note>

## When does a Chat Agent make sense?

Deploy a chat agent whenever your users naturally prefer typing over talking. 

* **Website Support:** Embed a widget to instantly field product, billing, or order inquiries without human intervention.
* **SMS Conversations:** Run aggressive two-way texting via a Twilio number for automated appointment reminders and rescheduling logic.
* **In-App Assistants:** Power a seamless, fully integrated chat interface directly inside your proprietary web or mobile app.

## How do you create a Chat Agent?

You can quickly spin up a brand new chat agent directly from the dashboard, selecting the appropriate logic engine for your conversational needs.

<Steps>
  <Step title="Start a new agent">
    Navigate to **Agents** in the dashboard, click **Create an Agent**, and explicitly select **Chat Agent**.
  </Step>

  <Step title="Choose an agent type">
    Select **Single prompt** for fluid, free-form interactions, or **Conversational flow** for deterministic, highly structural routing. *(Note: Custom LLM is restricted to voice).*
  </Step>

  <Step title="Set up the agent">
    Define your [base prompt](/build/prompt-engineering-guide), attach functional tools, link a knowledge base, and configure chat-specific timeouts.
  </Step>
</Steps>

## How do you convert an existing Voice Agent?

Converting an existing voice agent automatically duplicates its configuration into a **brand-new chat agent**. The original voice agent remains completely active and untouched.

<Steps>
  <Step title="Open the voice agent">
    Inside the agent builder, click the **More options** dropdown in the top-right corner and select **Convert to Chat Agent**.
  </Step>
  <Step title="Confirm">
    Acknowledge the dialog confirming that the original agent will not be modified, and click **Convert**.
  </Step>
  <Step title="Review the new chat agent">
    The dashboard will load the new chat agent. **Crucial:** Any voice-only components (like `call transfer` nodes or `press digit` IVR navigation) are aggressively deleted during the conversion. You must review the flow to fix broken edges.
  </Step>
</Steps>

## What settings are unique to Chat?

While chat agents share core configurations with voice agents, they utilize specific timeout mechanics to handle inactive user sessions gracefully.

* **Auto-close inactive chats:** Define exactly when an idle chat session automatically terminates (`end_chat_after_silence_ms`). This can be configured anywhere from 2 minutes to 72 hours.
* **Auto-close message:** Send a customized sign-off message (`auto_close_message`) immediately before the agent automatically ends the session.

## How do you deploy a Chat Agent?

Because chat agents are inherently headless, Tavly relies on you to surface the interface to end-users via widgets, SMS, or custom API integrations.

* **Website Widget:** Drop a single `<script>` tag into your site's codebase for instant text chat without requiring a backend. Read the [Website Widget Guide](/deploy/chat-widget).
* **SMS Integration:** Connect your agent to a Twilio phone number to accept inbound and outbound texts. Read the [SMS Guide](/deploy/enable-sms).
* **Custom API Integration:** Build a completely bespoke interface utilizing [Create chat](/api-references/create-chat) to initialize the session and [Create chat completion](/deploy/create-chat-completion) to handle message transmission.


Once your agent is live, set up [alert rules](/features/alerting-overview) around chat volume, success rate, negative sentiment, or cost, so you hear about problems without needing to watch the dashboard constantly.

## FAQ

<AccordionGroup>
  <Accordion title="Can a chat agent run on my own custom LLM?">
    No. Chat agents only support Tavly's own LLM response engines (single and multi prompt) plus conversation flow — custom LLM agents are limited to voice.
  </Accordion>

  <Accordion title="Does converting a voice agent modify or delete the original?">
    No. Conversion produces an entirely separate chat agent; the original voice agent is left untouched, and any phone numbers attached to it keep functioning normally.
  </Accordion>

  <Accordion title="What are the ways a chat session can end?">
    Three ways: the agent itself ends it (through an end-chat node or function), you end it manually via the [End chat API](/api-references/end-chat), or the user simply goes quiet past the inactivity timeout and Tavly closes the session automatically.
  </Accordion>

  <Accordion title="How is billing calculated for chat agents?">
    Chat is billed per message the agent sends, and add-ons like guardrails are also charged per message. Check [pricing](/pricing) for current rates.
  </Accordion>
</AccordionGroup>
