## What are LLM Configuration Options?

LLM options allow you to deeply fine-tune how the underlying language model processes logic and generates responses. Adjusting these settings—specifically Temperature, Structured Output, and Fast Tier routing—directly impacts your agent's conversational reliability, latency, and operational cost.

<Note> **Model Constraints:** Not every configuration option is supported by every LLM. Check your dashboard interface to verify which settings are unlocked for your selected model.</Note>

## How do you tune Temperature?

Temperature dictates how deterministic or creative the LLM's outputs are. Ranging from 0.0 to 1.0, this setting controls the mathematical probability distribution the model uses to select its next words.

### General Temperature Guidelines

| Temperature | Behavior Profile | Best Used For |
| :--- | :--- | :--- |
| **0.0 – 0.3** | Highly consistent, strict, and deterministic | Function calling, exact data collection, technical support |
| **0.4 – 0.7** | Balanced consistency and conversational variation | General customer service, inbound sales calls |
| **0.8 – 1.0** | Highly creative, varied, and unpredictable | Creative brainstorming, casual virtual companions |

## When should you enable Structured Output?

Structured Output forces the LLM to generate responses that strictly conform to a predefined JSON schema. You should enable this exclusively when your agent relies on mission-critical function calling, as it guarantees the model cannot output malformed or missing arguments.

**Operational Benefits:**
* **Total Reliability:** Completely eliminates hallucinated parameters or malformed function arguments.
* **Proactive Error Handling:** Structurally prevents invalid API calls from being executed.
* **Format Consistency:** Guarantees every data output strictly matches your backend schema.

**The Trade-offs:**
* **Development Friction:** Schema caching slows down how quickly agent configuration updates save.
* **Initial Latency:** The absolute first execution immediately following a configuration change may load slower.
* **Zero Deviation:** The agent physically cannot deviate from the required format, even to explain an error.

**Verdict:** Always enable for financial, medical, or API-heavy agents. Leave off during rapid prototyping or for agents with loose conversational objectives.

## What is Fast Tier (Premium Performance)?

Fast Tier forcefully routes your LLM traffic through dedicated, high-priority inference infrastructure. This premium tier actively suppresses latency variance, delivering significantly faster, more predictable voice responses.

**Performance Impact:**
Internal benchmarking demonstrates the following physical improvements when Fast Tier is active:
* **50% reduction** in latency variance.
* **25% faster** average response generation.
* **99.9% uptime availability**, compared to the 99.5% standard tier average.


### The Main Benefits

1. **Consistent latency** — response times stay predictable, call after call.
2. **Higher availability** — gets priority access to compute resources.
3. **Less variance** — processing speed fluctuates far less than usual.
4. **A smoother experience** — conversations feel more natural as a result.

### What It Costs

<Warning>
  Fast Tier is priced at **1.5x the standard rate** for whatever model you're using. Weigh the ROI for your specific use case before turning it on.
</Warning>

### When Fast Tier Makes Sense

✅ **Good fit for:**

* High-value customer interactions
* Time-sensitive operations — emergency services, urgent support, that kind of thing
* Premium service tiers
* Demos and sales calls

❌ **Probably not necessary for:**

* Internal testing
* Low-volume or non-critical calls
* Cost-sensitive applications
