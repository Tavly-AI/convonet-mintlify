## What are Content Guardrails?

Tavly provides native content moderation guardrails that evaluate conversational turns against strictly defined policy categories. 

When a statement breaches an active policy, the system suppresses the non-compliant generation and speaks a compliant placeholder message. This mechanism allows the call to remain active and secure without abrupt interruption.

## How does the Moderation Architecture work?

Guardrails intercept dialogue at two distinct evaluation boundaries: before the agent processes a prompt, and before the agent speaks its response.

* **Input Guardrails:** Screens incoming caller speech *before* sending transcripts to the core language model. When caller requests trigger a restriction (like a jailbreak attempt), the agent returns an immediate refusal placeholder rather than fulfilling the malicious prompt.
* **Output Guardrails:** Screens candidate agent responses *prior* to text-to-speech rendering. If the generated text touches a restricted category (like financial advice), Tavly drops the response and synthesizes a safe fallback phrase instead.

<Note> **Call Continuity:** Under both conditions, the call session continues normally. Guardrail triggers do not terminate phone lines, initiate transfers, or invoke tools—they strictly replace offending messages with benign responses.</Note>

## How do you Configure Guardrails?

You can configure moderation rules when creating or updating agents via the REST API or the Tavly Dashboard. In the console, navigate to **Security & Fallback Settings** to toggle specific compliance topics.

<Info> **Performance Impact:** Active moderation inspection introduces approximately 50ms of processing latency per conversational turn.</Info>

## What Categories are Moderated?

### Output Topics

Tavly natively screens outgoing agent generation against nine distinct compliance categories to ensure safe corporate deployments:

| Policy Key | Covered Content |
| :--- | :--- |
| `harassment` | Abusive phrasing, intimidation, or hateful language |
| `self_harm` | Discussions or instructions regarding self-inflicted harm |
| `sexual_exploitation` | Sexually explicit or exploitative material |
| `violence` | Violent acts, physical aggression, or threats |
| `defense_and_national_security` | Classified intelligence, defense tactics, and military operations |
| `illicit_and_harmful_activity` | Unlawful conduct, malicious exploits, or prohibited goods |
| `gambling` | Betting, wagering, and gambling promotion |
| `regulated_professional_advice` | Licensed professional counsel (legal advice, medical diagnoses, financial planning) |
| `child_safety_and_exploitation` | Exploitative content involving minors and child safety violations |
