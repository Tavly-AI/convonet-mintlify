## What is a Global Node?

A **Global Node** is a universally accessible conversational state that can be seamlessly reached from any point in the active conversation flow, without requiring strict edge connections.

It is specifically designed for handling highly unpredictable, universal intents that could happen at any moment during a call—such as a caller randomly stating `I want to talk to a human`, `I need to call back later`, or `What is your refund policy?`. By simply toggling **Global Node** in the node's settings, it becomes omnipresent.

## How do you set up a Global Node?

You define a strict transition condition directly on the node itself. Because the node floats globally over the graph, it inherently does not require regular wired edges.

For example, you could define the entry condition as: `When user indicates this is not a good time to continue`. Now, no matter where the caller currently is in the flow, if they say `I need to call back later`, the agent instantly routes to this global node.

## How do you train Global Node behavior?

You explicitly train the underlying model to accurately recognize the global intent by uploading concrete conversational examples directly into the node.

* Click **+ Add** in the node settings to create an example transcript.
* Mark the exact transcript as either **Jump to global node** or **Not jump to global node** to definitively teach the model boundary cases.

<Note> **Evaluation Timing:** Global nodes strictly evaluate *after* the caller speaks. Therefore, every single fine-tuning example must end on a user utterance. Read the [Fine-Tune Examples Guide](/build/conversation-flow/finetune-examples) for more details.</Note>

## How do you return to the previous node?

You can configure the global node to temporarily interrupt the flow, handle the request, and instantly return the caller to their exact prior position.

1. Toggle on **Go back to previous node**.
2. A new **Go Back Condition** menu appears.
3. Define the explicit trigger for returning (e.g., `User changed their mind and wants to continue the call`).

Go-back conditions support both prompt-based and deterministic equation-based logic. You can stack multiple go-back conditions and dictate execution priority by dragging them into order.

## How do you prevent endless loops?

If a caller continuously repeats phrasing that matches the global trigger, you can forcefully pause the node to prevent infinite conversational loops.

Turn on the **Prevent Immediate Re-Trigger** setting. This aggressively locks the global node for a designated number of **Node steps** (defaulting to 3 turns) immediately after it fires, forcing the conversation to progress rather than stalling out in a loop.
