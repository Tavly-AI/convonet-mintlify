## What is an End Node?

An **End Node** is a strict terminal block that definitively closes out an active call. It possesses no outgoing edges, meaning the call automatically ends the exact instant the AI agent enters the node. You can seamlessly deploy as many end nodes as required to handle various conversational conclusions.

By default, the agent hangs up instantaneously. To prevent this from feeling overly abrupt to the human caller, you can enable **Speak During Execution** to enforce a polite closing phrase.

For example, an appointment-booking flow might utilize one End Node for a successful booking (e.g., "You're all set for Tuesday. Goodbye!") and a completely separate End Node to handle a cancellation path with a different closing sentiment.

## How does it compare to the End Call Tool?

The End Node and the [End Call Tool](/build/single-multi-prompt/end-call) both terminate the session, but they are deployed for entirely different architectural paradigms.

* **End Node:** Deploy this when the call must terminate deterministically at a fixed, hardcoded point in the visual flow (e.g., explicitly after a payment succeeds).
* **End Call Tool:** Attach this tool to a [Subagent Node](/build/conversation-flow/subagent-node) when the LLM needs the autonomous freedom to end the call dynamically mid-conversation whenever it logically decides the overarching goal is achieved.

## What node settings are available?

The End Node provides targeted settings to dictate exactly how the agent physically hangs up the phone and how easily the node can be reached by the rest of the flow.

* **Speak During Execution:** Activating this feature reveals a dedicated text field where you define the exact closing message the agent delivers immediately before hanging up.
  * **Prompt:** The LLM dynamically generates a contextual farewell based on your foundational instructions.
  * **Static Sentence:** The agent strictly reads the exact wording you provide (e.g., `Goodbye, have a nice day`).
* **Global Node:** Transforms the End Node into a universally reachable destination from anywhere in the flow the moment its condition is met (e.g., `User wants to end the call or says goodbye`). This eliminates the need to draw physical edges from every single node. Read the [Global Node Guide](/build/conversation-flow/global-node).
