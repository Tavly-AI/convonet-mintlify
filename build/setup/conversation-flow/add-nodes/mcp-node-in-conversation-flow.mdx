## What is an MCP Node?

An **MCP Node** securely triggers and executes tools hosted on an external **Model Context Protocol (MCP)** server during a live AI phone call. 

While this structural node is not strictly intended for holding a fluid conversation with the caller, the agent can optionally speak while the tool executes to prevent awkward dead air.

<Note> **Different architectures:** For single-prompt and multi-prompt agents, MCP servers are connected entirely differently (via the response engine). Read the [MCP Tools for Single/Multi-Prompt Agents](/build/single-multi-prompt/mcp) guide.</Note>

## How do you add an MCP server?

You must globally register your external MCP server with Tavly before you can deploy it as a node inside a specific conversation flow.

<Steps>
  <Step title="Add the server">
    First, register the base MCP server in your Tavly environment.
    <Frame>
      <img src="https://mintcdn.com/retellai/zL2HeUqUnagEN9eK/images/cf/mcp/add_mcp.png?fit=max&auto=format&n=zL2HeUqUnagEN9eK&q=85&s=6dee07c5d03c2be78acfce15d7d8e724" width="734" height="589" data-path="images/cf/mcp/add_mcp.png" />
    </Frame>
  </Step>

  <Step title="Add request headers (Optional)">
    You can specify rigid custom HTTP headers to authenticate the outbound requests Tavly makes to your MCP server.

    Headers and query parameters are the **exclusive** mechanism Tavly uses for authentication. The most common implementation is an authorization header like `Authorization: Bearer <token>`. Tavly fundamentally does not handle interactive OAuth flows on your behalf; you must programmatically fetch your own OAuth access tokens and inject them via headers.

    <Tip> **Dynamic Authentication:** Header values securely support [Dynamic Variables](/build/dynamic-variables). This allows you to pass a unique, session-specific token per individual call, such as `{{access_token}}`.</Tip>

    <Warning> **Security Best Practice:** To strictly restrict your MCP server so it only accepts traffic from Tavly, explicitly whitelist Tavly's static outbound IP address: `100.20.5.228`.</Warning>

    <Frame>
      <img height="200" src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/custom-function/headers.png?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=44295c732912fcb1c3f29259e3f59609" data-path="images/custom-function/headers.png" />
    </Frame>
  </Step>

  <Step title="Add query parameters (Optional)">
    You can seamlessly define rigid query parameters that Tavly will dynamically append to your MCP server's endpoint URL during execution.
    <Frame>
      <img height="200" src="https://mintcdn.com/retellai/YMPW7mFNipo6shGp/images/custom-function/query-params.png?fit=max&auto=format&n=YMPW7mFNipo6shGp&q=85&s=0a0ccd469644d04aa87c086a8dc68bfb" data-path="images/custom-function/query-params.png" />
    </Frame>
  </Step>

  <Step title="Add the MCP tool">
    Once the server is authenticated, select the explicit **MCP Tool** you wish the node to execute.
    <Frame>
      <img src="https://mintcdn.com/retellai/32uO5g9DswfoJ9j7/images/cf/mcp/add_tool.png?fit=max&auto=format&n=32uO5g9DswfoJ9j7&q=85&s=ad49026f6f2a42a5e14a5abcd82e0cfa" width="725" height="365" data-path="images/cf/mcp/add_tool.png" />
    </Frame>
  </Step>

  <Step title="Map response values to variables (Optional)">
    You can aggressively parse specific JSON values out of the returned MCP tool's response body and instantly save them as **Dynamic Variables** for subsequent flow logic.

    For instance, if the external server returns user data, you can extract the user's name and reference it globally afterward as `{{user_name}}`.

    **Example JSON response body:**

    ```javascript theme={"dark"}
    {
      "properties": {
        "user": {
          "name": "John Doe",
          "age": 26
        }
      }
    }
    ```

    <Frame>

    </Frame>
  </Step>
</Steps>

## What node configurations are available?

The MCP Node provides targeted settings to dictate exactly how globally accessible it is and how transitions are logically calculated.

* **Global Node:** Transforms the MCP Node into a universally reachable execution point from anywhere in the flow. Read the [Global Node Guide](/build/conversation-flow/global-node).
* **Fine-Tuning Examples:** Inject custom examples explicitly into this node to teach the LLM how to parse complex or unexpected JSON responses. Read the [Fine-Tune Examples Guide](/build/conversation-flow/finetune-examples).
