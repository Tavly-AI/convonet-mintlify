## What are the basic agent settings?

Before writing a single line of your prompt, you must configure three fundamental choices that determine how your **Tavly AI agent** sounds and behaves. You need to select a **language model**, choose a **voice**, and configure the **welcome message**. With these settings established, your agent is capable of holding a call.

<Steps>
  <Step title="Pick a language model">
    Open the model selector in the toolbar above the agent editor. Options are organized into three distinct groups: **Versatile and highly intelligent**, **Fast and cost-efficient**, and **Speech to speech**. Each entry clearly lists its relative cost per minute.

    If you are unsure where to start, select any model tagged **Suggested**. These models offer the optimal trade-off between quality, latency, and cost. You can switch models later without rewriting your prompt, ensuring flexibility as new language models emerge.

    </Frame>
  </Step>

  <Step title="Choose a voice">
    Next to the model dropdown in the agent toolbar is the **voice control**.

    <Frame caption="The voice control sitting next to the model selector.">
      <img src="https://mintcdn.com/retellai/ccDgYqUTi0dx_57A/images/agent-voice-control.png?fit=max&auto=format&n=ccDgYqUTi0dx_57A&q=85&s=a75c99b819776298fd7ee5e9845fa100" alt="The agent toolbar showing the model dropdown and a voice control" style={{ maxHeight: 560 }} width="1800" height="452" data-path="images/agent-voice-control.png" />
    </Frame>

    Clicking it opens the **Select Voice** dialog. Each voice explicitly displays its accent, apparent age, provider, and the crucial **voice ID** (necessary for programmatic API configurations). Utilize the **play button** on each card to preview, and apply **Gender**, **Accent**, and **Search** filters to narrow the list effectively.

    <Frame caption="The Select Voice dialog, with each card showing a preview control and its voice ID.">
      <img src="https://mintcdn.com/retellai/ccDgYqUTi0dx_57A/images/agent-voice-library.png?fit=max&auto=format&n=ccDgYqUTi0dx_57A&q=85&s=1bf186d01961c32fc4ed585ca01a9e9c" alt="The Select Voice dialog open" style={{ maxHeight: 560 }} width="1690" height="1024" data-path="images/agent-voice-library.png" />
    </Frame>

    * **Bringing your own voice:** Clone a voice via the **Platform Voices** tab, or import one from a custom provider account using the **Custom Providers** tab. See the [custom voice guide](/build/voice) for full details.
    * **Adjusting pace:** The Voice Speed slider ranges from 0.5x to 2.0x (default is 1.0x). Enabling **Dynamically adjust based on user input** allows the agent to intelligently match the caller's speaking pace in real time. Callers can also instruct the agent to speed up or slow down verbally during the call.
  </Step>

  <Step title="Set who opens the call">
    Below the prompt field, the **Welcome Message** setting strictly governs how the conversation initiates:

    * **User speaks first:** The agent waits silently until the caller speaks.
    * **AI speaks first:** The agent initiates the call. You must configure exactly how it opens:
      * **Dynamic message:** The agent composes a unique, contextual opening line for each call based on your prompt.
      * **Custom message:** The agent strictly reads a fixed text line you provide.

    When selecting **AI speaks first**, a **Pause Before Speaking** control appears. Increase this delay if the agent tends to jump in abruptly before the caller has fully answered the phone.

    <Frame caption="Welcome Message set to AI speaks first, with the second dropdown open on Dynamic message.">
      <img src="https://mintcdn.com/retellai/ccDgYqUTi0dx_57A/images/agent-welcome-message.png?fit=max&auto=format&n=ccDgYqUTi0dx_57A&q=85&s=f3af9df2f6336bb63e10d92fb5f13641" alt="The Welcome Message setting below the prompt box." style={{ maxHeight: 560 }} width="1800" height="373" data-path="images/agent-welcome-message.png" />
    </Frame>
  </Step>
</Steps>

## What advanced configurations are available?

The remaining panels in the agent editor provide comprehensive control over advanced call behaviors. While these settings are optional for getting a basic call working, they allow you to fine-tune knowledge bases, optimize speech dynamics, handle voicemail gracefully, and extract vital post-call data for production environments.

<Steps>
  <Step title="Write your prompt">
    The primary text box holds the agent's core persona, identity, and task instructions. For multi-prompt agents, this acts as the global prompt governing every distinct state. Refer to the [write a single prompt](/build/single-multi-prompt/write-single-prompt) and [write a multi prompt](/build/single-multi-prompt/write-multi-prompt) guides.
  </Step>

  <Step title="Set up a knowledge base">
    Provide authoritative reference material by uploading documents, URLs, or raw text to improve factual accuracy. Review the [knowledge base guide](/build/knowledge-base).
  </Step>

  <Step title="Adjust speech settings">
    Manage how the agent speaks and handles conversational turn-taking:
    * **Background sound:** Play an ambient sound bed (e.g., call center noise) to construct a natural auditory atmosphere.
    * **Response Wait time:** Set a deliberate pause (up to 5.5 seconds) before the agent replies to a caller. Increasing this accommodates slower talkers. The **Dynamically adjust** toggle lets the agent automatically vary wait times based on the caller's specific pacing.
    * **Interruption Sensitivity:** Dictate exactly how readily the agent yields when it detects the caller talking over it.
    * **Reminder frequency:** Define how frequently the agent nudges a persistently silent caller.
    * **Pronunciation:** Create a dedicated [pronunciation guide](/build/add-pronunciation) for specialized vocabulary.

    <Frame caption="The Response Wait time control under Speech Settings.">
      <img src="https://mintcdn.com/retellai/GtSB6YKE5JLSJhGy/images/response-wait-time-slider.png?fit=max&auto=format&n=GtSB6YKE5JLSJhGy&q=85&s=685487463543e07499528c3627cbf8eb" alt="The Response Wait time setting in Speech Settings" style={{ maxHeight: 560 }} width="760" height="185" data-path="images/response-wait-time-slider.png" />
    </Frame>
  </Step>

  <Step title="Adjust call-handling settings">
    Govern the mechanical and routing aspects of the call:
    * **Voicemail handling:** Detect and intelligently manage voicemails. See [Handle Voicemail](/build/handle-voicemail).
    * **End call on silence:** Define the exact duration of silence permitted before automatically terminating the call.
    * **Call duration:** Set the strict maximum total duration allowed for any single call.
  </Step>

  <Step title="Adjust real-time transcription settings">
    Enhance the precision of caller input detection:
    * **Denoising Mode:** Adjust how aggressively background noise is algorithmically filtered from the caller's audio.
    * **Transcription Mode:** Select the dedicated speech-to-text model.
    * **Vocabulary Specialization:** Bias transcription heavily toward domain-specific terms (e.g., complex drug or product names) to ensure flawless accuracy.
  </Step>

  <Step title="Set up post-call data extraction">
    Configure the platform to automatically extract structured information (like booked appointments or caller sentiment) from completed calls. Check the [Post Call Extraction guide](/features/post-call-analysis-overview).
  </Step>

  <Step title="Configure security and fallback options">
    * **Data Storage and PII Settings:** Opt out of securely storing call recordings, transcripts, or sensitive personal data.
    * **Secure URLs:** Serve recordings exclusively via signed, expiring links (1 minute to 7 days).
    * **Fallback Voice:** Assign a resilient backup voice in case the primary provider fails mid-call.
    * **Guardrails:** Apply strict programmatic restrictions on permitted agent topics.
    * **Default Dynamic Variables:** Provide fallback values for prompt variables if none are supplied at call initiation.
  </Step>

  <Step title="Set up webhooks">
    Connect external endpoints to securely receive real-time call event payloads. Refer to [register a webhook](/features/register-webhook).
  </Step>
</Steps>

With your foundational settings correctly configured, your agent is fully capable of handling basic calls. To introduce complex interactivity and logic, your next crucial step is to attach custom tools and explore comprehensive prompt templates.
