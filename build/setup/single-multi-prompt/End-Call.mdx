## How do you enable automatic call termination?

Out of the box, a Tavly AI agent will not hang up on its own. To enable autonomous call termination, you must add the **End Call** tool to your agent and define precise conversational conditions in the core prompt to trigger it.

<Steps>
  <Step title="Add the End Call Tool">
    Navigate to the tools section of your agent dashboard, click **+ Add**, and explicitly choose **End Call** from the available list of functions.

    <Frame>
      <img height="700" src="https://mintcdn.com/retellai/rxvYffEkEJPRL1KD/images/end_call.png?fit=max&auto=format&n=rxvYffEkEJPRL1KD&q=85&s=53ae902cbe4dbfa4edff788fff3ca94e" alt="Adding end call tool" data-path="images/end_call.png" />
    </Frame>
  </Step>

  <Step title="Decide When the Call Should End">
    Work out the precise conversational conditions that should accurately trigger termination. For instance, define exactly what the caller might say to indicate the interaction is definitively over.

    * "If the user says 'thank you', 'goodbye', or 'bye', use the `end_call` tool to terminate the conversation."

    <Frame>
      <img height="700" src="https://mintcdn.com/retellai/rxvYffEkEJPRL1KD/images/end_call_2.png?fit=max&auto=format&n=rxvYffEkEJPRL1KD&q=85&s=6fb7c7e1b1183a8b25eee5cfab6fb885" alt="Configuring end call conditions" data-path="images/end_call_2.png" />
    </Frame>
  </Step>

  <Step title="Reflect the Conditions in Your Prompt">
    You must strictly write those end-call conditions directly into the agent's main prompt so the language model reliably recognizes exactly when it is time to act.

    ```text
    If the user says 'thank you', 'goodbye', or 'bye', use the end_call tool to terminate the conversation.
    ```

    </Frame>
  </Step>
</Steps>

## How do you end a call through the API?

Beyond allowing the agent to hang up autonomously, you maintain absolute control over call termination programmatically via the API. You can manually stop live calls, provision tools dynamically, or manage custom websocket terminations.

* **Ending a call already in progress:** Send a secure request to [Stop Call](/api-references/stop-call) (`POST /v2/stop-call/{call_id}`) directly from your server to immediately sever an active live call.
* **Adding the tool programmatically:** When you [create](/api-references/create-retell-llm) or [update](/api-references/update-retell-llm) a Tavly LLM via the API, include a tool object configured with `type: end_call` inside the `general_tools` array. This programmatically mirrors the dashboard setup.
* **Bringing your own LLM:** If you are connecting a custom LLM over a WebSocket connection, simply inject `end_call: true` directly into your JSON response payload. Tavly will gracefully end the call only after the currently queued audio has finished being spoken. Full technical details are available in the [LLM WebSocket reference](/api-references/llm-websocket).
