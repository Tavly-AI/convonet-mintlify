## What is Tavly AI?

**Tavly AI** is a comprehensive platform designed to **build, validate, ship, and monitor AI-driven voice and chat agents**. It seamlessly handles **phone connectivity**, **prompt design**, **tool calling**, and **reporting** all inside one unified environment, streamlining the creation of sophisticated conversational workflows.

## How do you build an agent?

Every **Tavly agent** starts with one of two foundational building blocks, which then layer on the same powerful **call-handling**, **retrieval**, and **integration capabilities**. You can create agents using **standalone prompts** for flexible, dynamic interactions, or **node-based workflows** for strict, predictable call structures. Head to the [full build reference](/build/overview) to see the complete configuration surface.

## How do you test agents before deployment?

Nothing has to touch a real caller until you are highly confident in its behavior. You can **test your agents interactively in text or real audio**, or **run automated test suites**, before an agent ever takes a live call. Compare the available testing methodologies on the [testing overview](/test/test-overview) page to ensure robust quality assurance.
