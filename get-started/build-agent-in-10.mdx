## How do you build an AI agent in 10 minutes?

You can set up a working **Tavly AI phone agent** in about ten minutes by following a simple five-step process: **sign up**, **configure your agent**, **run a browser test call**, **attach a phone number**, and **place or receive a real call**.

<Steps>
  <Step title="Sign up for Tavly">
    1. Go to [tavly.it](https://www.tavly.it/)
    2. Create your account

    Every new account starts with **$10 in trial credit**. You will not be asked for a credit card unless you decide to purchase a dedicated phone number.
  </Step>

  <Step title="Configure an agent">
    1. Navigate to the **Agents** section and select **Create an agent**.
    2. Choose your agent type: **Single prompt** for lightweight, open-ended conversations, or **Conversational flow** for a rigid, predictable call structure suited to production.
    3. Decide your starting point: build manually from scratch, load a pre-built template (e.g., front-desk receptionist), or use the **Tavly AI Agent** to automatically generate a draft from a plain-language description (see [Tavly AI Agent](/tavlyaiagent/create-agent)).

    <Frame>
      <img height="200" src="https://mintcdn.com/retellai/MoqZ2YN1eciIk62m/images/create-agent-templates.png?fit=max&auto=format&n=MoqZ2YN1eciIk62m&q=85&s=2502d0beee48e4743dbfb0477e4ccb2d" alt="Agent creation screen showing types and templates." data-path="images/create-agent-templates.png" />
    </Frame>
  </Step>

  <Step title="Run a test call">
    1. Click **Test** to launch a live audio call with your agent directly inside the browser.
    2. Grant microphone permission when prompted, then speak to the agent exactly as a caller would.

    There is **no cost** and **no phone number needed** for this step. You can run as many test calls as you like on an unpublished draft.

    <Frame>
      <img height="200" src="https://mintcdn.com/retellai/2bc_YV-DZysjbtgO/images/test-agent-playground.png?fit=max&auto=format&n=2bc_YV-DZysjbtgO&q=85&s=e6727898af839baafefadcb0775b2108" alt="Agent editing screen with the conversation prompt and Run Test control." data-path="images/test-agent-playground.png" />
    </Frame>
  </Step>

  <Step title="Attach a phone number">
    1. Open the **Phone Numbers** section and select **Buy New Number**.
    2. Add a payment method if you have not already (via the **Add Payment Method** option or the **Billing** section).
    3. Enter the desired area code (Optional).
    4. Complete the secure purchase.
    5. In the number's settings, assign it to the agent you configured earlier.

    Numbers managed directly by Tavly are limited to the US and Canada, priced at **$2/month** for a standard line and **$5/month** for toll-free. To connect a telephony provider you already use for international numbers, see [custom telephony](/deploy/custom-telephony).

    <Frame>
      <img height="200" src="https://mintcdn.com/retellai/eDm7SYLrvELb5Shw/images/phone-number-config.png?fit=max&auto=format&n=eDm7SYLrvELb5Shw&q=85&s=0e73ad5463dea8e2c1d0ecab973f9d75" alt="Number configuration screen highlighting Inbound and Outbound Call Agents." data-path="images/phone-number-config.png" />
    </Frame>
  </Step>

  <Step title="Place or receive a real call">
    1. **For inbound calls:** Dial the phone number you just purchased.
    2. **For outbound calls:** Select **Make an outbound call** and type the destination number with its full country code (e.g., `+12137774445`).
  </Step>
</Steps>

## What can your deployed agent do?

Once your agent is fully deployed, it operates autonomously. It can securely **take inbound calls**, autonomously **place outbound calls**, and reliably carry on natural, spoken conversations **around the clock** without human intervention.

## What if my browser blocks microphone access?

If the browser will not let your test call use the microphone, you must open your browser's **site permission settings** for the Tavly dashboard and manually enable microphone access. Once enabled, refresh the page and try the **Test** button again.

## Is a phone number required to test Tavly?

**No, a phone number is not required.** You can run unlimited browser-based test calls against a draft agent completely free, with no phone number and no payment method. A number is only necessary when handling real phone calls.

## Can I use international phone numbers?

Through Tavly's internal inventory, you can only purchase **US or Canada numbers**. However, you can seamlessly connect an external telephony provider to use numbers from any country. For setup details, see the [custom telephony](/deploy/custom-telephony) guide.

## What happens if my card is declined?

If your payment fails, confirm your card details are correct and retry, or switch to a different payment method from the **Billing** section. See our guide on [adding a payment method](/accounts/add-payment) for a full walkthrough.
