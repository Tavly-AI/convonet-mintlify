## What is Live Monitoring and when should you use it?

**Live Monitoring** is a real-time supervision dashboard that provides instant operational visibility into active Tavly AI voice calls. It allows supervisors and quality assurance leads to stream live transcripts, silently monitor audio streams, inject steering context, execute human takeovers, or disconnect problematic calls before a session concludes.

While [Call and Chat History](/features/session-history) and [Post-Call Extraction](monitor/post-call-analysis-overview) process conversations after they finish, Live Monitoring provides immediate situational awareness for active telephony and web voice streams.

### Core Supervision Capabilities

* **Real-Time Quality Assurance**: Silently observe agent responses, pronunciation, and latency during peak dialing campaigns without callee detection.
* **Emergency Human Escalation**: Seamlessly take over conversation control when an AI agent encounters complex inquiries or when callers request human operators.
* **Compliance Auditing**: Spot-check high-value transactions and sensitive disclosures as they occur in real time.
* **Programmatic Steering**: Inject live conversational hints to guide the AI agent without taking over voice control.

## How do you access Live Monitoring and manage role permissions?

To **access Live Monitoring**, select Live Monitoring from the dashboard navigation panel. Workspace access is restricted by role-based permissions, requiring Admin, Developer, or custom call management write privileges. If PII scrubbing is enabled on an agent, supervisors must also hold raw-data viewing permissions to access mid-call unredacted streams.

### Security and Role Governance

* **Required Roles**: Live Monitoring is accessible exclusively to users with **Admin** or **Developer** roles, or custom roles granted explicit call write permissions. Users assigned the standard **Member** role cannot access active sessions. See [Access Control](/accounts/access-control).
* **PII Redaction Constraint**: Because [PII scrubbing](/accounts/privacy/data-storage) runs asynchronously post-call, live streaming transcripts display raw customer text. Supervisors must possess **Raw Data View** privileges to inspect calls handled by PII-scrubbed agents.

## How do you execute Live Listen, human Take Over, and call termination?

To **execute Live Listen, human Take Over, and call termination**, select your desired action button below the active transcript. Click Live Listen to monitor WebRTC audio silently, click Take Over to permanently disconnect the AI agent and bridge your browser microphone to the caller, or select End Call.

### 1. Live Listen (Silent Monitoring)
* **Zero Audio Bleed**: Transmits caller and agent audio to your speakers over WebRTC without broadcasting your microphone.
* **Invisible Monitoring**: Neither the caller nor the AI agent receives audible alerts or indicators that audio is being monitored.
* **Multi-User Auditing**: Multiple supervisors can listen to the exact same audio stream concurrently.

### 2. Take Over (Human Intervention)
* **Permanent Agent Detachment**: Disconnects the AI model from the call session entirely.
* **Browser Microphone Bridging**: Prompts for browser microphone access before deactivating the AI agent. If permission is denied, the takeover is cancelled and the agent continues speaking safely.
* **Exclusive Control**: Only one human supervisor can take over a call at any time.

<Warning>
  Taking over an active call **permanently deactivates the AI agent** for that session. The AI agent cannot resume control, live transcription pauses, and the call terminates when either human party hangs up.
</Warning>

## How do you integrate live monitoring and intervention in custom applications?

To **integrate live monitoring in custom applications**, initialize the Tavly Web SDK using a secure public key and connect to the monitor call WebSocket. Use client methods like listen, takeOver, and updateLiveCall to build custom supervisor consoles, stream real-time transcripts, and steer ongoing conversations programmatically.

Every supervision capability available in the dashboard can be integrated into custom enterprise contact center portals:

| Operational Action | REST / WebSocket API Endpoint | Tavly Web SDK Method |
| :--- | :--- | :--- |
| **Stream Live Transcript** | [Monitor Call WebSocket](/api-references/monitor-call-websocket) | `client.monitorCall({ transcript: true })` |
| **Listen to Live Audio** | WebRTC Media Gateway | `watch.listen()` |
| **Human Takeover** | WebRTC Media Bridging | `watch.takeOver()` |
| **Steer Agent in Text** | [Update Live Call API](/api-references/update-live-call) | `watch.updateLiveCall()` |
| **Terminate Session** | [Stop Call API](/api-references/stop-call) | `watch.end()` |

### JavaScript Web SDK Integration

```javascript monitor_call.js theme={"dark"}
import { RetellClient } from "retell-client-js-sdk";

// Initialize client with public key restricted to your domain
const client = new RetellClient({ key: "public_key_YOUR_PUBLIC_KEY" });

const watch = client.monitorCall({
  call_id: "call_119c3f8e47135a29e65947eeb34cf12d",
  hooks: {
    // connecting -> monitoring -> listening -> taken_over -> ended
    onStatus: (status) => console.log("Monitor status:", status),
    onTranscript: (transcript) => console.log("Live turn:", transcript),
    onError: (error) => console.error("Monitoring error:", error),
  },
});

// Trigger audio actions via explicit user gestures (required by browsers)
document.getElementById("btn-listen").onclick = () => watch.listen();
document.getElementById("btn-takeover").onclick = () => watch.takeOver();
document.getElementById("btn-disconnect").onclick = () => watch.end();
```

<Warning>
  **Security & Permission Isolation**: The ability to monitor and take over ongoing phone calls is a highly privileged operation. An API key possessing **Call → Edit** permissions can take over any active call across your entire workspace. Always isolate administrative credentials behind your secure application backend.
</Warning>

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Why is the Live Monitoring tab not visible in my dashboard?">
    Live Monitoring is restricted to workspace **Admin** and **Developer** roles, as well as custom roles assigned call management write permissions. Standard Members cannot view live calls. Contact your administrator to upgrade your role via [Access Control](/accounts/access-control).
  </Accordion>

  <Accordion title="Can callers or agents detect when a supervisor is listening in?">
    No. Live Listen operates purely as a receive-only WebRTC audio feed. Neither the caller nor the AI voice agent receives any audio cues or notifications while you monitor.
  </Accordion>

  <Accordion title="How many simultaneous viewers can monitor a single call?">
    Each active call supports up to **5 concurrent WebSocket transcript streams** (shared across dashboard users and API consumers). In contrast, an unlimited number of supervisors can connect to the live audio feed via Live Listen. Only **one supervisor** can execute a Take Over.
  </Accordion>

  <Accordion title="Can a supervisor coach or whisper to an AI agent during a live call?">
    Audio whispering is not supported. However, supervisors can inject private textual guidance using the [Update Live Call API](/api-references/update-live-call) with `call_control.additional_context`. Setting `trigger_response: true` instructs the agent to incorporate the advice naturally on its next turn.
  </Accordion>
</AccordionGroup>
