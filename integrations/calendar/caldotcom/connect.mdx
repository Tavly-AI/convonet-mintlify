## What is the Tavly AI Cal.com integration and when should you use it?

**Tavly AI Cal.com integration** links your Cal.com scheduling infrastructure to Tavly using a single workspace-level API key, giving voice and chat agents direct access to live scheduling tools. Agents check real-time availability, confirm and book appointments, or reschedule and cancel existing reservations directly during caller conversations without maintaining duplicate calendars.

Connecting Cal.com takes one API key and provisions [Cal.com agent functions](/integrations/calendar/caldotcom/agent-functions) across your entire workspace: your agents check real-time openings, book appointments, and look up, reschedule, or cancel existing reservations. A single workspace-level connection covers every agent, eliminating the need to paste individual API keys into separate tool configurations.

<Note>
  This integration replaces legacy built-in Cal.com tools. The Tavly dashboard no longer offers built-in tools, the API stops creating and updating them on **September 30, 2026**, and on **October 31, 2026**, Tavly will automatically migrate existing tools to this unified integration. Review the [deprecation notice](/integrations/calendar/caldotcom/connect) before that date: tools whose Cal.com API keys have expired will be skipped and will halt operation.
</Note>

### When to connect Cal.com

Connect Cal.com when customer bookings and consultations are managed within Cal.com and you require voice agents to handle scheduling end to end:

* **Present live calendar openings**: The conversational agent inspects real-time event type availability and offers valid, unbooked time slots directly to the caller.
* **Instant in-call booking**: Once the caller selects an open time, the agent confirms details, submits the reservation, and triggers Cal.com's automated confirmation workflows.
* **Autonomous reschedule and cancellation**: The agent queries upcoming appointments by attendee email, confirms the target reservation, and moves it to a new slot or marks it canceled.

> **Real-World Implementation:** A regional dental practice configures an inbound scheduling agent. When an existing patient calls to adjust an appointment, the agent queries upcoming cleanings via the caller's email, presents open slots for the following week, and reschedules the booking to Friday at 10:00 AM—all within a single two-minute phone call.

## What prerequisites are required before connecting Cal.com?

Connecting Cal.com requires an **active Cal.com account** with configured event types and knowledge of your hosted domain instance (**cal.com** or **cal.eu**). Users must be authorized to generate persistent API keys. EU accounts should note that cal.eu is scheduled for sunset on November 1, 2026, necessitating cal.com migration.

* **Cal.com Workspace Ownership**: A Cal.com user or team account with administrative rights to create API keys and manage target event types.
* **Regional Domain Awareness**: Confirm whether your account resides on the global instance (**cal.com**) or the European instance (**cal.eu**). You must generate the key on that specific instance and select the corresponding domain in Tavly.

<Note>
  Cal.com has announced that **cal.eu shuts down on November 1, 2026** (enterprise customers retain access through their contracted term). Transitioning to cal.com is opt-in. When migrating, generate a new key on cal.com and reconnect in Tavly using the `Cal.com` domain option.
</Note>

## How do you generate a never-expiring Cal.com API key?

To generate an API key, log in to Cal.com, navigate to **Settings → Developer → API keys**, and click **+ New**. Assign a recognizable key name (such as `Tavly AI`), ensure the **Never expires** toggle is activated to avoid unexpected service disruptions, click **Create**, and immediately copy the generated token.

<Steps>
  <Step title="Navigate to Developer Settings in Cal.com">
    Sign in to your Cal.com dashboard. In the left navigation sidebar, navigate to **Settings**, scroll to the **Developer** section, and select **API keys**.
  </Step>

  <Step title="Create a new persistent API token">
    Click **+ New** to open the key generation dialog. Ensure the **API key** tab is selected, and enter a descriptive name such as `Tavly AI`.
  </Step>

  <Step title="Toggle Never expires and copy token">
    Turn on the **Never expires** switch. Expiring keys cause sudden connection terminations when the expiration date lapses. Click **Create** and copy the secret token immediately; Cal.com displays the key string only once.

## How do you authenticate and connect Cal.com in the Tavly Dashboard?

In the Tavly Dashboard, navigate to **Integrations → Available**, select **Cal.com**, and click **Connect**. Specify an internal connection name, paste your never-expiring API key, select your regional domain (**Cal.com** or **Cal.eu**), and click **Connect** to run automated API verification and activate tools for all workspace agents.

<Steps>
  <Step title="Initiate connection in the Tavly dashboard">
    In the Tavly Dashboard, select **Integrations** from the primary menu, click the **Available** tab, locate **Cal.com**, and click **Connect** (or click **Add Account** if an existing connection is registered).
  </Step>

  <Step title="Configure connection parameters">
    Complete the connection modal fields:

    | Parameter | Setting / Value | Description |
    | :--- | :--- | :--- |
    | **Connection name** | `Cal.com - API key` | Descriptive internal alias distinguishing this connection within your workspace. |
    | **API Key** | `cal_...` secret token | The never-expiring API key generated in Step 1. |
    | **Domain** | `Cal.com` or `Cal.eu` | Matches the regional hosting environment of your Cal.com organization. |

## How do you troubleshoot common Cal.com connection errors?

Resolve Cal.com authentication issues by confirming your API key has not expired and that your selected domain (**Cal.com** or **Cal.eu**) matches your account's regional hosting. If a connection displays an error tag after prior operation, generate a new persistent API key in Cal.com and reconnect within the Tavly dashboard.

<AccordionGroup>
  <Accordion title="Connecting fails with an authorization error">
    Verify that your API key string was copied in its entirety without trailing whitespace. Ensure the **Domain** setting strictly corresponds to the instance hosting your account (`cal.com` vs. `cal.eu`). If your key was created without enabling **Never expires**, verify whether the token reached its expiration date in Cal.com settings.
  </Accordion>

  <Accordion title="The connection displays an error tag after prior successful operation">
    Tavly marks a connection as errored when subsequent API calls are rejected by Cal.com. This typically indicates that an administrator revoked the API key in Cal.com or that a time-limited key expired. Open connection settings on the **Connected** tab, paste a newly generated persistent API key, and click **Reconnect**.
  </Accordion>
</AccordionGroup>

## Frequently asked questions about connecting Cal.com

Cal.com connects via secure API keys targeting hosted cloud endpoints. Self-hosted instances are not supported. Legacy built-in tools remain operational until **October 31, 2026**, when Tavly automatically migrates valid keys to this workspace-level integration. Alternative scheduling platforms such as **Calendly** are also natively supported.

<AccordionGroup>
  <Accordion title="Does Tavly support self-hosted or open-source Cal.com instances?">
    No. The integration interfaces directly with Cal.com's hosted SaaS API infrastructure on `cal.com` and `cal.eu`. Custom self-hosted server deployments are not supported (as of September 2026).
  </Accordion>

  <Accordion title="How does the legacy built-in tool migration work?">
    Tavly automatically analyzes workspace agents using legacy built-in Cal.com tools. On **October 31, 2026**, Tavly provisions unified workspace connections for detected API keys and updates tool pointers while maintaining exact function signatures, ensuring existing prompt templates continue executing without interruption.
  </Accordion>

  <Accordion title="Can I connect multiple Cal.com accounts to a single Tavly workspace?">
    Yes. You can add multiple Cal.com connections under **Integrations → Available → Add Account**, allowing different agents to book appointments across distinct team accounts or department calendars.
  </Accordion>
</AccordionGroup>
