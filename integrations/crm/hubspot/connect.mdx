## What is the Tavly AI HubSpot integration and when should you use it?

The **Tavly AI HubSpot integration** connects your HubSpot CRM portal to Tavly via a private app access token. Connect HubSpot when it serves as your core system of record to greet existing contacts by name, enrich CRM properties with **Post Call Extraction**, log calls to activity timelines, and trigger live deals tools.

Authenticating a connection links your portal's contacts, deals, and companies to conversational voice agents while maintaining synchronized CRM records:

* **Instant Customer Identification**: Contacts sync automatically into Tavly, empowering agents to greet callers by name and reference their lifecycle stage without discovery friction.
* **Autonomous Property Enrichment**: Analysis metrics extracted from each call or chat write back directly to contact properties.
* **Unified Engagement Timelines**: Every conversation logs to the customer's timeline as a Call engagement or Communication activity with duration and transcript summaries.
* **Real-Time Enterprise Function Calling**: Dedicated [agent function tools](/integrations/crm/hubspot/agent-functions) look up deals, retrieve company details, and schedule follow-up tasks mid-conversation.

<Note>
  This guide covers configuring HubSpot as a **CRM data source**. If you want to trigger outbound voice calls directly from HubSpot enrollment workflows, consult the [HubSpot Marketplace app guide](/marketplace/hubspot). Both integrations operate independently and can be used together.
</Note>

## What prerequisites and permissions are required to connect HubSpot?

Connecting HubSpot requires a HubSpot account with **Super Admin** privileges. Only Super Admins can create private apps, configure API scopes, and generate secret access tokens. Before beginning setup, ensure administrative access to your target portal and review required contact, deal, and engagement scopes.

## How do you create a private app and configure scopes in HubSpot?

To create a private app, navigate to **Development → Legacy Apps** (or **Settings → Integrations → Private Apps**) in HubSpot and select **Create legacy app**. Assign a descriptive name, navigate to the **Scopes** tab, and grant necessary contact, deal, and company permissions. Finally, click **Create app** and copy your token.

## What scopes are required for contact sync, activity logging, and tools?

Contact sync and timeline logging require three foundational scopes: `crm.objects.contacts.read`, `crm.schemas.contacts.read`, and `crm.objects.contacts.write`. Enabling deal and company tools requires complementary read/write scopes (`crm.objects.deals.read/write`, `crm.objects.companies.read/write`, and their corresponding schema read scopes). Note and task creation endpoints authenticate through contact scopes without separate permissions.

On the **Scopes** tab, click **Add new scope**, search for each required permission, check the box, and click **Update**.

### Core Contact Synchronization & Activity Logging Scopes

| Scope Identifier | Operational Necessity |
| :--- | :--- |
| `crm.objects.contacts.read` | Ingests contacts, runs the connection validation test, and executes contact lookup tools. |
| `crm.schemas.contacts.read` | Reads contact property definitions for field mapping, tool inputs, and record queries. |
| `crm.objects.contacts.write` | Enables outbound sync, timeline engagement logging, and contact/note/task tool execution. |

### Optional Deal and Company Agent Function Scopes

If your agents will use deal or company [integration tools](/integrations/crm/hubspot/agent-functions#available-tools), grant the following complementary scopes:

| Scope Identifier | Required Agent Functionality |
| :--- | :--- |
| `crm.objects.deals.read` | Enables the **Get Deal** and **List Contact Deals** functions. |
| `crm.objects.deals.write` | Enables the **Update Deal** tool. |
| `crm.objects.companies.read` | Enables the **Get Company** and **List Contact Companies** functions. |
| `crm.objects.companies.write` | Enables the **Update Company** tool. |
| `crm.schemas.deals.read`, `crm.schemas.companies.read` | Reads custom property definitions when configuring and running deal/company tools. |

HubSpot routes call logs, tasks, and notes through standard contact write permissions; no dedicated engagement scope is needed. If an agent executes a function lacking scopes, HubSpot returns an HTTP `403` specifying the `MISSING_SCOPES` category. Granting the scope under [**Edit app**](#change-scopes) immediately resolves the error without generating a new token.

<Warning>
  **Configure Complete Scopes During Initial Setup**: A missing scope does not trigger a connection error badge in Tavly because HubSpot responds with an HTTP `403` rather than an authentication rejection. The specific function simply halts silently. The sole exception is `crm.objects.contacts.read`: because the handshake test queries contacts, missing this scope causes connection creation to fail outright.
</Warning>

## How do you connect and verify the HubSpot integration in Tavly?

To connect HubSpot, navigate to **Integrations → Available** in the Tavly dashboard, select **HubSpot**, and paste your private app access token into the **API Key** field. Tavly immediately tests authentication by requesting a contact batch; once verified, the card displays on the **Connected** tab ready for synchronization.

<Steps>
  <Step title="Generate and reveal the access token">
    In HubSpot, click **Create app** in the upper right corner. Review the confirmation prompt and click **Continue creating**. On the subsequent **Auth** tab, click **Show token** and copy the string.
  </Step>

  <Step title="Initiate connection in the Tavly dashboard">
    Open **Integrations** in Tavly, navigate to the **Available** tab, locate **HubSpot**, and click **Connect** (or **Add Account** if another portal exists).
  </Step>

  <Step title="Supply connection credentials">
    Configure the connection fields:

    | Parameter | Specification |
    | :--- | :--- |
    | **Connection name** | Workspace alias; defaults to `HubSpot - API key`. |
    | **API Key** | The secret private app access token generated in Step 1. |

## How do you rotate access tokens and manage private app scopes?

To rotate tokens safely, select **Rotate and expire later** under your app's **Legacy Apps** settings in HubSpot, preserving the previous token for 7 days. In Tavly, open connection settings and click **Reconnect** with the new token. Scope modifications take effect instantly in HubSpot without requiring token re-generation.

### Token Rotation Workflow

<Steps>
  <Step title="Rotate the token in HubSpot">
    In HubSpot, open **Development → Legacy Apps** and select your Tavly integration app. Beside the access token, click **Rotate**, then select **Rotate and expire later**. This maintains previous token validity for **7 days**, preventing active call interruptions while you update Tavly.
  </Step>

  <Step title="Reconnect the portal in Tavly">
    Navigate to **Integrations → Connected** in Tavly and open the HubSpot connection settings. Paste the new token into the masked credential field and click **Reconnect**. Tavly validates the new credential immediately; all existing field mappings and contact records remain intact.
  </Step>
</Steps>

### Modifying Scopes

To modify permissions, navigate to **Development → Legacy Apps**, select your app, and click **Edit app** in the upper right. Adding new scopes takes effect immediately without generating a new token or reconnecting. Removing a scope immediately disables dependent Tavly agent functions without flagging the connection as severed.

## How do you troubleshoot common HubSpot connection errors?

If initial connection fails, confirm you pasted the private app **access token** rather than a legacy API key or client secret, and verify `crm.objects.contacts.read` is granted. If an active connection errors with an HTTP 401, the token was deleted or expired; paste a freshly rotated token to reconnect.

### Diagnostic Matrix

* **Initial Connection Authorization Error**: Verify that the supplied string begins with the private app token prefix rather than an OAuth client secret or deprecated API key. Ensure `crm.objects.contacts.read` is enabled on the app.
* **HTTP 401 Unauthorized Error on Active Connection**: Occurs when a token is rotated with immediate expiration or deleted in HubSpot. Open connection settings in Tavly, input the valid token, and select **Reconnect**.
* **Silent Tool Execution Failures**: When agent function calls fail while the connection is green, inspect recent tool call logs for HTTP `403` status codes (`MISSING_SCOPES`). Add the missing deal or company scopes in HubSpot to restore functionality.
