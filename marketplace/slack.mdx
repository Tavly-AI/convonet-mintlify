# Trigger Tavly calls from Slack

> Install the Tavly AI Slack app to start outbound voice agent calls from Slack and post call summaries, results, and recordings back to channels.

This guide connects **Tavly AI** to Slack so team members can start outbound calls with a slash command. After each analyzed call, Tavly posts the result to the originating channel.

---

## What is the Tavly AI Slack app and how does it automate outbound calls?

The **Tavly AI Slack application** connects conversational voice agents directly to your Slack workspace, allowing team members to initiate automated outbound telephone calls using slash commands. Once a call concludes, Tavly automatically posts comprehensive conversation summaries, user sentiment analysis, audio recording links, and duration metrics back to designated channels.

By embedding AI voice agents directly into Slack, cross-functional teams (including sales, support, and operations) can trigger customer outreach instantly without leaving their central communication platform.

### Key capabilities and operational workflow

| Component | Technical Function | Operational Benefit |
| :--- | :--- | :--- |
| **Slash Command Dispatch** | Executes immediate outbound calls via `/tavly-call` or `/retell-call` | Enables one-click outbound calling from any active channel |
| **Webhook Delivery Engine** | Dispatches asynchronous webhook payloads on `call_analyzed` events | Automatically posts conversational data without manual polling |
| **Post-Call Summaries** | Formats sentiment, transcript highlights, and durations in Slack cards | Provides team-wide visibility into customer interactions |
| **Direct Recording Playback** | Embeds secure audio recording hyperlinks directly within messages | Facilitates instant QA review and audit trail verification |

## What prerequisites are required before installing the Slack integration?

Configuring the Slack integration requires **Slack workspace app installation permissions**, an active **Tavly AI account** equipped with an API key, configured voice agents, and an outbound phone number. You also need an accessible Slack channel for notifications (with `@Tavly AI` invited if private) and valid destination numbers formatted in **E.164**.

### System prerequisites checklist

Ensure all administrative permissions and account prerequisites are in place prior to launching the setup flow:

* **Slack permissions**: Administrative authorization to add and install third-party applications in your target Slack workspace.
* **Tavly account credentials**: An active Tavly AI account with a provisioned API key, at least one configured conversational voice agent, and an assigned outbound caller ID.
* **Designated Slack notification channel**: A public or private channel designated for receiving post-call results. If using a private channel, run `/invite @Tavly AI` before initiating calls.
* **E.164 phone number formatting**: All outbound test and production destination numbers must adhere to standard international E.164 syntax (e.g., `+15551234567`).

<Note>
  Use your own API key, webhook URL, agent, caller ID, channels, and test numbers. The screenshots use sample or masked values.
</Note>

## How do you register the Slack webhook URL with your Tavly agent?

Copy the unique endpoint from **Register the Webhook URL in Tavly** inside the wizard. In your Tavly dashboard, navigate to **Agents**, select your calling agent, expand **Webhook Settings**, paste the URL into **Agent Level Webhook URL**, verify connectivity using **Test**, and ensure the `call_analyzed` event trigger remains enabled.

<Steps>
  <Step title="Copy the generated webhook URL">
    In the setup wizard, find **Register the Webhook URL in Retell** (or Tavly) and select **Copy webhook URL**.

    <Frame>
      <img src="https://mintcdn.com/retellai/74XP5i9H3wbJHpKM/images/slack/screenshot-8.png?fit=max&auto=format&n=74XP5i9H3wbJHpKM&q=85&s=c4588c89b880668a244e8f0ac151f22d" alt="Tavly setup wizard showing the generated webhook URL and Copy webhook URL button" style={{ maxHeight: 560 }} width="1823" height="496" data-path="images/slack/screenshot-8.png" />
    </Frame>
  </Step>

  <Step title="Add the webhook URL to the Tavly agent">
    Open the Tavly dashboard, select **Agents**, and open the agent used for Slack. Expand **Webhook Settings**, paste the URL into **Agent Level Webhook URL**, and select **Test**. Under **Webhook Events**, make sure `call_analyzed` is enabled so Tavly can send the post-call result. Save or publish the changes.

    <Frame>

## How do you initiate outbound voice calls from Slack channels?

To place a call, type `/tavly-call` (or `/retell-call`) followed by a valid destination number in **E.164 format** directly into an authorized Slack channel. Slack returns an immediate ephemeral confirmation when dialing begins, and Tavly posts the final conversational summary, sentiment scores, and call recording link upon call completion.

Use the slash command for the fastest end-to-end test.

<Steps>
  <Step title="Run the slash command">
    In a channel where Tavly AI can post, enter the command below with a valid E.164 destination number. Slack displays a private confirmation when the call starts.

    ```text theme={"dark"}
    /tavly-call +15551234567
    ```

    <Note>
      Depending on your workspace app manifest, both `/tavly-call` and `/retell-call` slash commands are supported.
    </Note>

## How do you troubleshoot common Slack calling and notification issues?

Troubleshoot Slack calling errors by verifying that phone numbers follow international **E.164 formatting** and confirming `@Tavly AI` has been invited to private channels. If post-call messages fail to appear, verify that the designated API key is saved as a **webhook key** and that the agent's `call_analyzed` event is enabled.

| Problem | Root Cause | Recommended Resolution |
| :--- | :--- | :--- |
| **Slack is not connected** | Authorization token not finalized | Select **Connect Slack** in App Home, approve access, then reopen the Home tab. |
| **Setup will not complete** | Incomplete setup steps | Confirm the API key, caller ID, default channel, and webhook test are complete. |
| **Webhook test fails** | Truncated URL or missing permissions | Copy the full URL without editing it and complete the Slack connection before testing. |
| **Slash command says not connected** | Wizard steps incomplete | Finish the setup wizard. An admin may need to reconnect or reinstall the app. |
| **Invalid phone number** | Incorrect formatting or missing country code | Use E.164 format with a leading plus and country code (e.g., `+15551234567`), without brackets or spaces. |
| **No post-call message** | Missing bot access or disabled event | Check the originating channel, invite Tavly AI to private channels, and enable `call_analyzed`. |
| **Message goes to the wrong channel** | Default notification route misconfigured | Update the default notification channel in the setup wizard. |
| **Channel is not accessible** | Bot not invited to private channel | Invite Tavly AI to the private channel (`/invite @Tavly AI`) or use an accessible public or default channel. |
| **Wrong agent or caller ID** | Mismatched defaults in wizard | Update the default agent and caller ID in the wizard and confirm they match Tavly dashboard settings. |

## Frequently asked questions about triggering Tavly calls from Slack

The Slack integration allows team members to trigger outbound voice agent calls using slash commands and receive conversational summaries and recordings automatically. Tavly supports one active webhook integration per key, requires E.164 phone formatting, and delivers instant notifications to public or private channels once post-call analysis concludes.

<AccordionGroup>
  <Accordion title="How do you trigger an outbound phone call from a Slack channel?">
    Type `/tavly-call` (or `/retell-call`) followed by the destination phone number in standard E.164 international format (e.g., `/tavly-call +15551234567`) in any channel where the bot is authorized.
  </Accordion>

  <Accordion title="Why is a designated webhook key required for Slack post-call summaries?">
    Tavly routes post-call event data specifically through API keys designated as webhook keys. If a regular API key is used without the webhook flag enabled, call analysis data cannot post back to Slack.
  </Accordion>

  <Accordion title="Can Tavly post call summaries into private Slack channels?">
    Yes. Before initiating calls or selecting a private channel as the default notification destination, invite the bot by executing `/invite @Tavly AI` inside that private channel.
  </Accordion>

  <Accordion title="Can I use the Slack integration alongside Notion or Zoho webhooks simultaneously?">
    Tavly accounts support one active webhook integration at a time per API key. If you are also utilizing Notion or Zoho integrations, designate which integration receives events or manage endpoints at the agent level.
  </Accordion>
</AccordionGroup>
