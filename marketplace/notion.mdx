# Trigger Tavly calls from Notion

> Connect Tavly AI to a Notion database to trigger outbound voice agent calls and write call summaries and recordings back to the originating row.

This guide details how to integrate **Tavly AI** with a **Notion database** so database automations can launch automated outbound phone calls. Once call analysis completes, Tavly automatically updates the originating Notion row with the conversation summary and audio recording link.

---

## What is the Tavly AI Notion database integration and how does it work?

**Tavly AI Notion database integration** enables Notion database automations to initiate outbound voice agent phone calls whenever row conditions are met. Following call analysis, Tavly writes the conversation summary, audio recording URL, and execution status back to the originating Notion record, establishing a closed-loop customer communication workflow.

When a Notion database row meets predefined trigger conditions (such as a status update or new phone entry), Notion fires a webhook to Tavly. Tavly validates caller consent, places the outbound call via your configured voice agent, and executes automated post-call writebacks when the conversation concludes.

### Prerequisites before starting

Before configuring the integration, ensure you have:
* A **Tavly AI account** with an API key, an active conversational agent, and an outbound telephone number.
* Administrative access to your target **Notion workspace and database**, with permission to authorize integrations and configure database automations.
* The **Tavly setup wizard for Notion**, provided by your integration administrator.

## What database properties are required to support Tavly call automation?

To support automated calling, your Notion database must include specific columns: **Name** (Title), **Phone** (Phone or text format with international country codes), **Call allowed** (Checkbox for compliance consent), **AI Summary** (Rich text for summaries), **Recording URL** (URL for audio playback), and an optional **Status** property.

### Database schema specification

| Property Name | Property Type | Operational Purpose | Configuration Notes |
| :--- | :--- | :--- | :--- |
| **Name** | Title | Identifies the customer or call recipient. | Default primary key in Notion databases. |
| **Phone** | Phone or Text | Stores the recipient's destination phone number. | Must include international country code (e.g., `+15551234567`). |
| **Call allowed** (example) | Checkbox | Controls calling consent and compliance checks. | The property name can be customized but must match the setup wizard exactly. |
| **AI Summary** | Rich text | Receives the post-call conversational summary. | Populated automatically following post-call analysis. |
| **Recording URL** | URL | Stores the clickable audio playback link. | Populated automatically following post-call analysis. |
| **Status** | Select or Text | Tracks call progress or acts as an automation trigger. | e.g., "Ready to call", "Called", "Needs follow-up". |

<Steps>
  <Step title="Create the call database in Notion">
    Open or create a Notion database containing the required properties outlined above. Format all phone numbers with a leading plus and country code (e.g., `+15551234567`), and insert your consent Checkbox property (e.g., `Call allowed`).

Copy both the Retell webhook URL and Notion automation URL for subsequent configuration.

## How do you create and trigger the Notion database automation?

In your Notion database, create an automation named **Tavly Call Agent**. Set a trigger—such as **Phone is edited** or **Status becomes Call now**—and add a **Send webhook** action. Paste the Notion automation URL, include all database properties (specifically Phone and consent), and publish the automation to enable dialing.

<Steps>
  <Step title="Open database automations builder">
    In your Notion call database, click the lightning bolt icon in the top header to open database automations. Create a new automation and title it **Tavly Call Agent**.
  </Step>

  <Step title="Define trigger criteria">
    Select an event trigger that aligns with your operational pipeline:
    * **Phone is edited**: Initiates a call whenever a new phone number is inserted.
    * **Status becomes Call now**: Provides controlled, button-driven or status-driven call execution.

### Comprehensive troubleshooting guide

| Failure Scenario | Root Cause | Corrective Action |
| :--- | :--- | :--- |
| **Notion connection fails** | OAuth token handshake interrupted | Reconnect and re-authorize the target database. Verify OAuth redirect endpoints. |
| **Tavly cannot read rows** | Database excluded from page grant | In Notion, navigate to **Settings → Connections → Active Connections**, find Tavly, and share the database. |
| **Automation does not fire** | Trigger criteria unmet or consent unchecked | Ensure the automation is toggled ON, the trigger condition fired, and **Call allowed** is checked. |
| **Notion webhook errors** | Incomplete property payload | Edit the webhook action in Notion and ensure **Phone** and consent are included in payload properties. |
| **No summary or recording link** | `call_analyzed` event disabled | Check Tavly agent settings to confirm the writeback URL is assigned and `call_analyzed` is active. |
| **Phone number rejected** | Missing country code | Ensure phone numbers adhere to E.164 formatting with leading plus sign (e.g., `+15551234567`). |
| **Data reaches wrong row** | Mismatched database association | Ensure the automation belongs to the exact database shared with the setup wizard. |

## Frequently asked questions about Notion call automation

Notion database automations trigger Tavly outbound calls using configured webhook endpoints. Call writeback requires designating an API key as a webhook key and subscribing to `call_analyzed` events. Calls are restricted strictly to rows where the designated consent checkbox property is marked, preventing accidental or non-compliant dialing.

<AccordionGroup>
  <Accordion title="Can I pass dynamic variables from Notion to the Tavly agent?">
    Yes. When you configure the **Send webhook** action in Notion, all selected row properties are forwarded in the webhook payload. You can reference these variables in your agent prompt to greet contacts by name or tailor conversational context.
  </Accordion>

  <Accordion title="What happens if the consent checkbox is left unchecked?">
    Tavly strictly inspects the consent property before initiating any outbound call. If the designated checkbox (e.g., `Call allowed`) is false or empty, Tavly skips dialing to protect compliance.
  </Accordion>

  <Accordion title="How quickly are summaries and recordings written back to Notion?">
    Writebacks occur asynchronously immediately after Tavly's post-call analysis engine finishes processing the conversation, typically within 15 to 45 seconds of call termination.
  </Accordion>

  <Accordion title="Does Tavly support multiple active webhook integrations?">
    Tavly workspaces support one primary workspace webhook destination at a time. However, agent-level webhook URLs can be configured individually per agent, allowing distinct endpoints for Notion, CRMs, or internal databases.
  </Accordion>
</AccordionGroup>
